# quick overview
This repo was created to serve as a template for using [obsidian](https://obsidian.md/). It includes all the settings and plugins I use and it should hopefully work straight out of the box. There is documentation included in the vault (in the 0.getting-started folder) that should hopefully help you through getting started with it. Lastly, there are some example files that I left in that you can of course incinerate whenever you want (as long as you don't incinerate the templates (I promise that they are useful)).

# recommended further reading
If you want to start doing your own customizatin you can refer more detailed documentation about some of the things mentioned in the documentation I wrote:
  - [Tasks plugin](https://publish.obsidian.md/tasks/Introduction) (**this is excellent**)
  - [Zotero integration plugin](https://community.obsidian.md/plugins/obsidian-zotero-desktop-connector)
  - [Templater plugin](https://community.obsidian.md/plugins/templater-obsidian)
  - [Periodic notes plugin](https://community.obsidian.md/plugins/periodic-notes)
  - [Git plugin](https://publish.obsidian.md/git-doc/Start+here)
    
The rest of the plugins are kind of set it and forget it
