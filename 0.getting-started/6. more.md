# templates
You can achieve a lot with templates, using the templater plugin.
Some templates can be found in the "x_templates" folder in this vault.
Templates can be used to quickly create notes of a specific kind.
Some of there are used by other plugins to like the [[3. literature work flow|zotero integration plugin]] which uses the [[literature note]] template.
Templates can be really simple or be really elaborate.
They can contain javascript snippets that automatically import information when creating a new note from a template (*Alt + N*) or when adding a template to an existing note (*Alt + E*).
You can edit templates as you like, the scripts associated with some of the plugins are in a hidden folder (.obsidian/plugins/~).
# git
If you want you can have obsidian automatically commit, push, and pull changes you make to your vault.
The plugin to set it up is included in this vault but is not active.
You will find it by clicking on the cog symbol in the bottom of the left panel under "Community plugins".
