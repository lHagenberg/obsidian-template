# tasks and non-tasks
As part of the [[2. basic concepts|basic functionality]] of obsidian you can create "tasks".
The Tasks plugin greatly expands on that by allowing you to create many types of "tasks" and "non-tasks" that can serve as visual signifiers in notes and provide ways to create quick overviews.
Tasks are always created by placing - [ ] at the beginning of a line.
Some examples are:
- [a] for the aim or objective of a paper
- [*] for ideas
- [?] for questions
- [!] for important points 
**Not all these task types are meant to make to do lists, but they an also be used to categorize information so you can retrieve it later** (see task queries)
you can find a full overview in here: [[Tasks Plugin - Task statuses]]
# task properties
Tasks can be assigned properties that help with categorization and planning. 
You can schedule tasks, set due dates, add priority signifiers etc. (again, more information in the developers documentation)
- [ ] this task is scheduled for today ⏳ 2026-06-02 
- [ ] this task is due today 📅 2026-06-02 
- [ ] this is a high priority task 🔺 
These properties are useful for at a glance overviews, but mostly allow for categorization in task queries (see task queries)
# task queries
Task queries really make allow you to create overviews of tasks.
The way this works it that obsidian will retrieve tasks and non-tasks from notes across your vault based on criteria that you set.
Some examples of those can be found in [[To Read]], [[To Cite]], [[To Investigate]], [[task dump]], and daily/weekly notes created from the [[journal dailies]] and [[journal weeklies]] templates ,respectively.
*You can find loads of information on how to create custom task queries in the documentation of the plugin provided by the developer.*

# sophisticated to do lists
I created a bunch of templates that allow you to create notes for each day and week (links are mentioned in the paragraph above).
Their task queries are aware of each other and allow you to keep track of things you are planning to do for each day and week.
Clicking on a day or week number in the calendar view (top left in the panel on the left) will create a new note using those templates of none already exists.
