Obsidian makes use of markdown (I am not sure if that is a language or a just a file format or both).
Everything in obsidian is made up of files, and the program is just an interface.
All the files are stored in vaults, which is basically just a reference to a folder structure that obsidian can interact with.
Obsidian is all about **connections**.

You can open the command pallette with *Ctrl + P*, there you will be able to access all the commands you can execute in obsidian.
You can use *shortcuts* that are mentioned in this documentation or use the command pallette.

# links
Files can be connected using "links".
Links are created by surrounding text with square brackets "[[]]".
Here comes a link that brings you back to [[1. an organized mess|the beginning]].
You can also display contents of linked files in the current file using "![[]]".
here is ![[an example]]
You can link to the file name, but also to "aliases" defined in the frontmatter (see file properties).
# file properties
Each file can be assigned properties that are defined in the YAML frontmatter at the top (and only at the top) of a file.
The frontmatter opens and closes with ---.
Properties are one of the key elements that allow you to organize, categorize, and find notes back.
You will see how this works when we get to actually [[3. literature work flow|reading and storing knowledge]].

# tasks
You can create to do lists and more with tasks.
Tasks are created with "- [ ]" at the beginning (and only the beginning) of a line.
- [ ] this is something to do
- [x] this is already done
- [/] this in progress
- [-] this no longer needs doing
This is only the beginning.
The task functionality is greatly expanded by the tasks plugin (see settings and plugins)
