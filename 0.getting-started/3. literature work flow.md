# literature workflow
The Zotero integration plugin allows obsidian to draw information from Zotero and see the files that it has access to.
This allows you to import a lot of metadata from Zotero and organize notes accordingly.
To import notes I set up a [[literature note]] template that is used to pull information from papers in your Zotero library and start taking notes.
Notes created from the template are automatically named using the *cite key* and places in the "2. papers" folder.
*In order for this to work you will need to place a .bib file in your vault's main folder.*

To create a new literature not use Ctrl + P to open the command panel and search for "Zotero integration: add paper", OR use the Ctrl + L shortcut.
This will open a drop down where you can search for papers in your Zotero library that can be imported.
**In order for this to work you need to have Zotero running on your computer.**
Once your paper is imported you can start taking notes.

On import the template will import the highlighted text in Zotero.
If you highlight more text after creating a note you can employ a script to import newly highlighted text into your existing note.
this is done by pressing *Alt + E* and searching for "update highlights".

*BEWARE‼️: when importing literature notes, existing literature notes by the same notes will be overwritten.*
The template script (currently) has no way of accounting for existing notes.
If you are willing you can probably add that functionality to the import script.
# literature database
Paper notes created in this method will become visible in the [[Paper Database.base]].
This database provides an overview of all created notes in your papers folder.
# read next
The [[To Read]] overview shows any "tasks" that you create inside literature notes.
The assumption here is that you only create tasks in literature notes for papers you will want to read next.
